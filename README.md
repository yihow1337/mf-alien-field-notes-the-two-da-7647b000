An alien tourist files a hotel-style review of Earth and rates the planet four stars, docking one for staff turnover: the entire workforce is replaced every eighty years. The joke is the visitor's angle — human mortality logged as a management complaint — and it lands on the last word. `main.py` copies the line from `entry.txt` to `entry.txt` in the output directory, 146 ASCII bytes, the same bytes on every run.

## Run it

```sh
python3 main.py
```
